# Hi there 👋 I'm CodeUltimate

![Profile Views](https://komarev.com/ghpvc/?username=CodeUltimate&color=blue)

Senior Software Engineer working on **real-time, high-throughput financial systems**. Currently leading architecture on a transaction screening platform processing payments in real time — Java 21, Spring Boot, Kafka, Kubernetes, built on hexagonal architecture with DDD and CQRS.

Before that: five years building post-trade systems for energy commodities trading, and digital services for the UK Home Office.

I care about clean domain boundaries, tests that actually catch things, and systems that stay comprehensible at scale. Outside the day job I build mobile and web products end to end — Flutter apps, Next.js frontends, and the infrastructure underneath them.

- 🔭 Working on: event-driven screening pipelines, ISO 20022 schema tooling, regulatory data flows
- 🌱 Currently exploring: framework-free CQRS in modern Java, Keycloak entitlement modelling
- 💬 Ask me about: DDD, hexagonal architecture, Kafka, Spring Boot, concurrency, Flutter
- 🤝 Open to collaborating on: fintech/payments infrastructure, developer tooling

## 🧭 How I build

- **Hexagonal / DDD** — domain layer stays free of framework imports, always
- **CQRS** where reads and writes genuinely diverge, not as a default
- **Tests owned by developers** — unit, integration and performance, not thrown over a wall
- **Event-driven by default** for anything that needs to scale independently
